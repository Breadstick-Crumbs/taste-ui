# Changelog

## 0.1.0 (2026-10-20)

First public release.

- `taste-ui` skill: build a taste profile from sites you love, design from it (fit check, questions with defaults, three directions, tokens first), and check the result with screenshots, interactions, journeys and an independent critique.
- `scripts/capture.mjs`: measures reference sites (computed type, colours by area, radii, shadows, motion libraries, header behaviour at several scroll depths, sticky/snap/scroll-driven effects, keyframes, transitions) and takes desktop and phone screenshots.
- `scripts/shoot.mjs`: screenshots at 375, 768 and 1280 px plus console errors.
- Templates for `TASTE.md` and per-site notes, and a worked example profile (text only).
- Works as a Claude Code plugin marketplace or as a plain skill folder.
