# Example profile

The author's own taste profile, built with this skill from 15 sites: product sites, e-commerce, an immersive brand site and a consumer AI app. It's here to show what a finished profile looks like: specific, measured, and written as taste rather than rules.

Only the text is included. The notes mention screenshots and measurement files (`top.jpg`, `tokens.json`, `motion.json`) that were captured privately and are not published, because they show other people's websites. To rebuild them for your own reference:

```bash
node skills/taste-ui/scripts/capture.mjs examples/example-profile wisprflow=https://wisprflow.ai mindtrip=https://mindtrip.ai
```

Use it as a model for your own `TASTE.md`, not as your taste.
