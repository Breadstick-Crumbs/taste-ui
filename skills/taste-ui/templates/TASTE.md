## Fundamentals (always)
Ordinary UI craft. These are the only hard rules.
- **One coherent type system:** one or two families, a clear scale, used consistently.
- **A deliberate palette, used consistently,** with readable contrast (WCAG AA for text).
- **Consistent spacing and radius logic.** The same kind of element looks the same everywhere.
- **Clear hierarchy:** one primary action per view.
- **Real content:** real names, numbers and places; no lorem ipsum, no invented metrics or testimonials.
- **Works everywhere:** phone width without horizontal scroll, keyboard and focus states, `prefers-reduced-motion`.
- **Right for the market:** currency, language and right-to-left layout where relevant.
- **Every state is designed:** empty, loading, error, partial and success.
- **Forms respect people:** labels, inline validation that says how to fix it, nothing lost on an error, no unneeded fields.
- **Comfortable on a phone:** tap targets of at least 44 px, body text of at least 16 px.
- **Fast:** sized and lazy-loaded images, preloaded fonts with a fallback, no layout shift.
